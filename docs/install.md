# Install the migration factory

> The install is **chapter three of the manual**, not a separate document. This page is a
> shortcut to it. Start at [the manual](manual/README.md) if you want the whole picture,
> including what the product does and why a resize is not enough.

Read the install chapters in this order:

1. [Before you install](manual/install/before-you-install.md): what the install creates, what it costs, and what you need.
2. [The choices you make first](manual/install/choices.md): the two questions the install asks, explained.
3. [Install step by step](manual/install/step-by-step.md): every command, with what you see at each step.
4. [After the install](manual/install/after-install.md): give the product permission to see your machines, and give people access.

The manual opens in a browser from the file `manual/index.html`, and from the dashboard under **Get help**, **Read the manual**.
